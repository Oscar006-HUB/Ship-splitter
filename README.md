# Shipping Cost Splitter

Browser tool that splits a shared shipping bill across the products in one shipment, so each item gets its true landed cost.

**Live tool:** https://oscar006-hub.github.io/Ship-splitter/

## Features
- Add any number of products with supplier price and quantity
- Separate currencies for supplier prices and the shipping bill
- Include other costs such as duty and handling
- Split shipping by value or by weight
- Apply a profit margin to get a suggested selling price
- Copy the results as a table

## Tech stack
A single HTML file with vanilla JavaScript — no dependencies.

## Running locally
Clone the repo and open `index.html` in a browser.
